Pay & Prove: agents pay, the court decides.

An AI buyer pays an AI seller through an x402-style payment. The funds sit in a GenLayer intelligent escrow. If the seller does not deliver, the buyer disputes — and the Internet Court (GenLayer LLM consensus) adjudicates on-chain and renders a verdict: release or refund. No human judge. No chargeback department. Just a verdict.

01

Pay · x402

Buyer agent requests a good. The seller answers 402 Payment Required with price + escrow terms. Buyer pays; funds lock in escrow.

02

Escrow · GenLayer

A PayProveEscrow intelligent contract holds the funds and the deal facts on Studio Next (chain 61997).

03

Dispute

Seller silent? Buyer calls dispute() with a reason. The deal moves to adjudication.

04

Verdict · Internet Court

adjudicate() runs LLM consensus: a leader proposes a verdict, validators independently re-judge. Agreed verdict executes.

Reproduce it

  1. Read the contract — contract/PayProveEscrow.py. The adjudication mirrors the portal's own WizardOfCoin pattern: gl.nondet.exec_prompt inside gl.vm.run_nondet_unsafe(leader_fn, validator_fn).
  2. Deploy — scripts/build_deploy_escrow.mjs builds the addTransaction calldata with genlayer-js; scripts/sign_broadcast.py signs with the vault wallet (1-param eth_estimateGas — the GenLayer node rejects 2-param calls).
  3. Drive a deal — scripts/build_call.mjs <contract> <function> '<json args>' then sign + broadcast the same way. See ONCHAIN_PROOF.md for the exact transactions that produced the two deals above.
  4. Run this page — open frontend/index.html (or serve this folder). It re-reads both deals live from Studio Next and falls back to the verified snapshot if the RPC is unreachable.
